# PRODUCT REVIEW MODE ON
## Project Rules

---

# Mission

Build a professional web application that helps affiliate creators generate high-quality product review content.

This application is NOT an AI image generator.

Its purpose is to become an AI Creative Director that produces:

- Product Review Storyboards
- Scene Planning
- Image Prompts
- Video Prompts
- Creative Direction

---

# Core Principles

## 1. Product First

The product is always the hero.

Never redesign the uploaded product.

Always preserve:

- Shape
- Material
- Color
- Texture
- Logo
- Pattern
- Stitching
- Size
- Details

---

## 2. Character Lock

Every project uses one consistent creator.

Do not change:

- Face
- Hairstyle
- Age
- Skin tone
- Body proportion

unless the user explicitly changes it.

---

## 3. Scene Logic

Every scene must have a clear marketing purpose.

Avoid meaningless actions.

Every scene should demonstrate:

- product usage
- product benefit
- product interaction
- buying motivation

---

## 4. Simplicity First

Always implement the simplest solution.

Avoid:

- unnecessary abstraction
- over engineering
- premature optimization

---

## 5. Sprint Discipline

Implement ONLY what exists in 03_TASK.md.

Never build future features.

Never guess future requirements.

---

## 6. Coding Rules

- Keep project runnable.
- Small commits.
- Small changes.
- Edit only affected files.
- Never rewrite the whole project.
- Preserve previous features.

---

## 7. Workflow

For every sprint:

1. Read PROJECT_RULES
2. Read ARCHITECTURE
3. Read TASK
4. Summarize understanding
5. Create implementation plan
6. Wait for approval
7. Implement
8. List modified files
9. Explain testing steps
10. Wait for QA

Never skip this workflow.

---

## 8. UI Rules

Default UI should be:

- Modern
- Clean
- Professional
- Dark Theme
- Beginner Friendly

Advanced settings should stay hidden until needed.

---

## 9. Quality Standard

Every completed task must:

- Build successfully
- No TypeScript errors
- No console errors
- Responsive
- Clean code
- Easy to extend
